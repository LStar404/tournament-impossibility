# 竞赛图哈密顿路极值序列的不可能性结果

这里是《哈密顿路极值序列的非代数性与公式限制》这一部分的独立仓库：论文与配套 Lean 4 形式化。
原先它作为子目录放在研究笔记仓库里，现在单独成库，便于单独引用与审阅。

  结论用 Mathlib 的标准谓词 `Transcendental (Polynomial ℂ)` 表述。截至 2026-11-09 05:00 UTC 的已核验记录覆盖 170 个模块；

## 边界

两项外部前提写在定理类型里，没有声明成公理，也没有在本仓库中重新证明：

1. 归一化极值序列趋于 `cosh(1)/cos(1)`，来自论文引用的图论渐近定理。
2. `exp(1), exp(-1), exp(i), exp(-i)` 在代数数系数下线性无关，即 Lindemann–Weierstrass 的有限特例。

修订版 v0.4 新增 A.5–A.6：有理值 q-regular 序列的幂次归一化极限必须有理，因而实际 a_n、m_n 及 P(n) 的数字线性表示可不依赖 R 排除。A.5 的完整有理极限定理现已形式化：任意有理值 q-regular 序列的 n^k 归一化有限极限属于 ℚ，不需要超越性输入。a_n、m_n 的非 q-regular 性以及 P(n) 无固定数字线性表示亦已形式化。
条件 R、单位圆是自然边界、非 D-finite、非 P-recursive 及伸缩关系等结论未形式化；对实际序列的这些应用仍以 R 为假设。
研究笔记固定于 c049e040，包含实际 R 的证明路线。F/J 到 R(C=L,r0=4) 的解析推导已核对；上游结构与恢复长链尚未全部独立复核，详见论文附录 B 的依赖说明。
生成函数非代数不等于没有闭式，也不等于计算困难。

## 已验证的上游引理

已验证内容分为三组：

- 有限组合与矩阵引理：有序消去、颜色词交换与零菱形修复、实际向量弱主序、各整数次幂的Frobenius范数比较、真实S1卷积及两永久式平均，以及无额外分解假设的小菱形六阶缺陷界。
- 实参数源级数：在 $q\ge0$ 且 $q(n-1)^2<1$ 时，实际源预解式等于已证明收敛的源能量级数，并可与传递竞赛图比较。
- 零菱形复圆盘：有限核行列式恒等式、复紧集一致极限及明确的 $O_R(1/n)$ 误差；固定 $0\le R<\pi/2$ 上，统一阶数阈值覆盖全部零菱形图与 $|w|\le R$。二次核真双边可逆，其欧氏逆算子范数不超过 $C_R^2$，其中 $C_R=2(1+R)e^R/\cos R$。若实际得分 $b=S\mathbf1$ 满足 $\lVert b\rVert_2^2\le Kn$，则普通源项 $|b^{\mathsf T}(I+(w/n)^2S^2)^{-1}b|/n^2\le KC_R^2/n$。

最后一组算子界使用显式逆条目和真实欧氏算子范数，未把行列式下界当成增长维数下的逆范数界；实得分能量及Hermitian/普通转置源项之间的桥接亦已证明。线性能量条件仍是独立前提，不能从零菱形性单独推出。

零点归一化的高斯参数分支、实际源项及组合因子的解析性现已验证。对实际零菱形竞赛图，若独立满足得分能量 $\lVert S\mathbf1\rVert_2^2\le Kn$，则按该分支定义的 $G_n\exp(\Lambda)$ 在固定嵌套圆盘 $0\le r<R<\pi/2$ 上趋于 $e^{vz}/\cos z$；每固定阶复导数均有显式 $O_{j,r,R,K}(1/n)$ 误差，阶数阈值统一于图、圆盘点及复参数 $|v|\le1$。导数界来自较大圆盘函数值估计及Cauchy界。已证明 $G_n^2\det(\beta I+(z/n)^2S^2)=1$ 和 $G_n(0)=1$，而非仅定义同极限的无关函数。

对原始双分支 $v^2=1$，现已从真实 $2n$ 维分块矩阵独立定义源二次式，证明其等于已消元的实际指数，同时建立真双边逆和同一归一化高斯分支的分块行列式恒等式。复参数 $|v|\le1$ 的推广只涉及此前定义的因子；分块恒等式仍要求 $v^2=1$。

有限全配对桥已证明：分块协方差的全部完美配对权重和等于真实矩阵永久式。每条无向边恰取一个代表端点，同色边导致零权重，二部配对与排列间有显式双射；空情形 n=0 的两端均为一。此为交换半环上的有限代数恒等式，不涉及正高斯测度。

对子集的有限桥也已证明：先将原矩阵限制到实际左右子集 I,J，不等势时配对和为零，等势时等于显式枚举下所选子矩阵的永久式。全局平方自由乘积展开及按子集大小归并冻结系数 F_k 已证明：实际子集配对权重定义的线性系数收缩作用于 prod(1+X)，得到 sum_k F_k z^k，并有 F_0=1、次数不超过 n。该收缩忽略含重复变量的单项式，仅足够这里的平方自由乘积，尚不是一般Wick泛函。另已按独立出现位置建立保留重复标签的完整多项式线性Wick泛函，证明单项式取值及对称协方差下任意枚举不变性。出现位置配对矩的完整四阶式也已证明，保留对角贡献；这不冒充新多项式映射的兼容端点。完整Wick与旧收缩在平方自由基单项式及真实prod(1+X)上的兼容已证明，但不宣称两个映射在一般多项式上相等。任意阶删除递归由真实配偶—残余配对双射及边权分解推出；奇数矩为零、空矩为一亦已证明。形式线性及二次指数恒等式与重求和、一般阶乘矩计数、投影因子Z、活动估计、真实系数尾界、下降阶乘恢复及完整R仍未完成。形式协方差通常不定，不能误作该协方差下的正高斯测度积分。双语PDF已更新到170模块的已核验数学范围；模块数量只记录构建快照，不代表全文所有结论均已形式化。

模块数以 `lean/verification/result.json` 的具体构建快照为准，不等于已证明论文的全部结论。
