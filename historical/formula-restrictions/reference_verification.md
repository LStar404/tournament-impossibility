# 参考文献核对记录

2026-11-02。核对限于正文四条指定引文及其作者／出版方原始页面；
不是完整新颖性或优先性检索。没有数学程序运行，也未重新审核旧恢复证明链。

1. **Divoux–Wang [1]。** 作者为Alexander Divoux和Shouda Wang，准确题名为
   *The maximum number of Hamiltonian cycles in tournaments*。
   虽然题名说cycles，正文 **Theorem 1.4** 明确讨论所有 \(n\) 点竞赛图的路径最大数，
   给出 \(P(n)=(\cosh1/\cos1\pm o(1))n!/2^{n-1}\)，沿全部整数趋于无穷。
   固定版本为[arXiv:2610.23755v1](https://arxiv.org/abs/2610.23755v1)，提交日期2026-10-16。
   首页自署August 10, 2026，不应替代提交日期。
   arXiv页面提供的DOI为10.48550/arXiv.2610.23755，并注明pending registration；
   本次确认了该标识符，但不声称其解析已完成，故同时保留固定版本链接。

2. **Popescu [2]。** 作者为Sever Angel Popescu，引用固定为
   [arXiv:2306.14352v2](https://arxiv.org/abs/2306.14352v2)，修订日期2023-09-17。
   本文需要的是[Theorem 3.2](https://arxiv.org/html/2306.14352v2)：
   互异代数数的指数在代数数域上线性无关。
   Theorem 3.1只陈述在有理数域上线性无关，不能代替3.2。
   该文是现代自含证明来源，不是十九世纪首次证明的论文。

3. **Stanley [3]。** [作者MIT主页保存的正式论文](https://math.mit.edu/~rstan/pubs/pubfiles/45.pdf)
   已核：p.175的Definition 1.1／Theorem 1.2给D-finite定义及等价方程；
   p.176的Definition 1.3给P-recursive定义，Theorem 1.4处理有限项修改，
   Theorem 1.5给普通生成函数D-finite与系数P-recursive的等价性。
   年份、卷期、页码和DOI与出版方元数据一致。

4. **Allouche–Shallit [4]。** [作者预印本](https://cs.uwaterloo.ca/~shallit/Papers/as0.pdf)
   的Definition 1.1给 \(k\)-kernel，Definition 2.1给regular定义，
   Theorem 2.2给有限核模与固定矩阵表示的等价形式。
   [作者书目](https://cs.uwaterloo.ca/~shallit/papers.html)明确说明在线预印本与正式版略有差异；
   不能把预印本pp.2–4直接当作正式版页码。
   该页另列Theorem 2.7勘误，本文所用定义和Theorem 2.2不依赖那条证明。

非P-recursive和伸缩关系排除结果，应继续明确附加R；非代数性短证明的独立来源与之区分。
本次不证明“无任何闭式”或计数NP／#P困难性。
