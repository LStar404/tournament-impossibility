# Actual ordered-join cycle additivity

cycleSum is the finite real sum of 0/1 indicators of genuine directed triples.
The module proves no cycle crosses an ordered two-block join, then proves
additivity for the actual recursively constructed ordinal block matrix.
For real Tournament blocks the summands equal the established actual
TournamentSourceEnergy.cycleCount cardinalities. No assumed count-additivity
or graph decomposition theorem is used.
