# Actual small-diamond pivot count reduction

For an actual integer-sign tournament with n≥4, D>0, and 24D≤n², the theorem
constructs a source switch with genuine unordered cyclic-triangle count r>0,
nr≤4D, and 6r≤n. D and r are actual finite-set cardinalities. Switching
preserves the actual diamond set, proved through the Pfaffian criterion.

This module does not assume block sizes and does not itself construct the SCC
ordered decomposition or prove the final sixth-moment gap.
