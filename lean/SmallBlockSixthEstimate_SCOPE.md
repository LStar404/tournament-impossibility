# Small-block sixth polynomial estimate

This is a finite real-polynomial inequality, not a standalone graph theorem.
It proves the sixth deficit polynomial is at least
(16 n^3 −56 n h^2 +32 h^3 −16 n) r under explicit nonnegative block/deficit
conditions, m_i ≤ h ≤ n, and r≤nh²/24. If additionally n≥4, h≤n/2 and
D≤(n−3)r, it proves the lower bound 6n²D.

The application to ACTUAL matrix deficits is in OrdinalTournamentDeficit, which
discharges Q,L,t nonnegativity and the triangle-total bound. This module alone
does not establish any triangle or diamond counting interpretation.
