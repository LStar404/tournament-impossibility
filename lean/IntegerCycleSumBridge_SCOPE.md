# IntegerCycleSumBridge scope

The matrix is Matrix.of applied to the entrywise real cast of the actual integer sign matrix T.S on the identical generic finite carrier V. No conversion to Fin n is needed.

Intended endpoints identify the existing OrdinalTriangleAdditivity.cycleSum with the real cast of the actual directedTriples.card and then with three times the actual cyclicTriangles.card. The final endpoint rewrites the actual diamond incidence bound using that cycleSum.

This module does not introduce an SCC decomposition, assert a switching-invariance of ordinary triangle counts, or assert Assumption R. The sourceSwitch interface remains separate.
